# 医院自助机系统

一个基于 Vue 3 和 Vite 构建的医院自助机系统，提供预约挂号等功能，支持竖屏显示。

## 功能特性

### 首页
- 医院 Logo 区域
- 功能模块导航（预约挂号、就诊服务、缴费结算、报告查询、病历查询、系统设置）
- 设备信息显示（设备编号、当前时间、在线状态）

### 预约挂号功能
- 科室选择（内科、外科、妇产科、儿科、眼科、耳鼻喉科、口腔科、皮肤科）
- 医生列表（包含医生姓名、职称、科室和预约状态）
- 时间选择（提供多个可预约时间段）
- 患者信息填写（姓名、身份证号、手机号码）
- 预约确认和提交

## 技术栈

- **Vue 3**: 前端框架
- **Vite**: 构建工具
- **CSS3**: 样式设计
- **JavaScript**: 交互逻辑

## 安装和运行

### 安装依赖

```bash
npm install
```

### 开发模式

```bash
npm run dev
```

访问 http://localhost:5173/ 查看项目

### 生产构建

```bash
npm run build
```

## 项目结构

```
website/
├── public/              # 静态资源
├── src/
│   ├── assets/         # 图片和样式资源
│   ├── components/     # Vue 组件
│   │   ├── HomePage.vue              # 首页组件
│   │   ├── AppointmentRegistration.vue  # 预约挂号组件
│   ├── App.vue         # 根组件
│   ├── main.js         # 入口文件
│   └── style.css       # 全局样式
├── index.html          # HTML 模板
├── package.json        # 项目配置
└── vite.config.js      # Vite 配置
```

## 主要组件说明

### HomePage.vue
- 首页布局

### AppointmentRegistration.vue
- 科室选择

系统已优化为竖屏显示，支持各种移动设备屏幕尺寸。
